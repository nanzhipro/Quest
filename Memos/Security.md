# 环境变量安全最佳实践

1. 环境变量管理

   - 永远不要将包含真实凭证的 .env 文件提交到版本控制
   - 使用 .env.example 作为模板
   - 生产环境使用安全的环境变量管理系统

2. 敏感信息处理

   - 避免在日志中打印敏感环境变量
   - 考虑使用环境变量加密存储
   - 定期轮换密钥和凭证

3. 访问控制
   - 限制环境变量的访问范围
   - 实施最小权限原则
   - 审计环境变量的使用情况
