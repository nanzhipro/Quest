# 环境变量配置指南

1. 开发环境

   - 使用 .env 文件管理环境变量
   - 保持 .env.example 更新
   - 本地开发使用 .env.development

2. 生产环境

   - 使用容器环境变量或云平台的环境变量管理
   - 实施环境变量加密
   - 使用密钥管理服务

3. 调试技巧
   - 使用日志验证环境变量加载
   - 检查环境变量优先级
   - 环境变量加载失败的故障排除
