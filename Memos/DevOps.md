# 日志配置

## 日志级别

可以通过环境变量 `LOG_LEVEL` 配置应用的日志级别：

- trace: 最详细的日志级别，包含所有调试信息
- debug: 调试级别，包含详细的运行时信息
- info: 信息级别，默认级别
- notice: 通知级别
- warning: 警告级别
- error: 错误级别
- critical: 严重错误级别

示例：

```bash
# 在启动应用时设置日志级别
LOG_LEVEL=debug vapor run
```

## 日志格式

日志包含以下信息：

- 时间戳
- 日志级别
- 消息内容
- 元数据（包含 app 名称、环境等信息）
- 源代码位置（如果提供）

## 日志监控

建议在生产环境中：

1. 配置日志聚合系统
2. 设置适当的日志级别（生产环境建议使用 info 或以上级别）
3. 监控错误日志的频率和内容
