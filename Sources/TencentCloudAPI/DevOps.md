# 语音识别服务运维备忘

## 环境配置

### 必要环境变量

```bash
# 腾讯云API凭证
TENCENT_SECRET_ID=<your-secret-id>
TENCENT_SECRET_KEY=<your-secret-key>
TENCENT_REGION=ap-guangzhou  # 默认使用广州区域，可根据实际需求修改
```

### 可选环境变量

```bash
# TLS配置（生产环境推荐使用）
TLS_CERT_PATH=/path/to/certificate.pem
TLS_KEY_PATH=/path/to/key.pem

# 日志级别
LOG_LEVEL=info  # debug, info, notice, warning, error, critical
```

## 性能调优

1. **内存管理**
   - 语音识别过程会消耗较多内存，尤其是处理大型音频文件时
   - 建议单个容器至少分配512MB内存
   - 监控内存使用情况，适时调整资源配置

2. **并发处理**
   - 语音识别是CPU密集型操作，建议根据CPU核心数设置最大并发请求数
   - 考虑使用异步处理队列，先快速响应客户端，后台处理识别请求
   - 在高负载情况下，考虑添加负载均衡和自动扩展策略

3. **超时设置**
   - 建议为语音识别请求设置合理的超时时间（通常15-30秒）
   - 实现请求追踪机制，便于排查超时问题

## 监控与报警

1. **健康检查**
   - `/health` 端点用于检查服务整体状态
   - 添加专用的语音服务健康检查端点，例如：`/api/v1/voice/health`

2. **指标收集**
   - 记录关键指标：请求量、响应时间、错误率、识别成功率
   - 按音频时长、格式类型分类统计性能差异
   - 监控腾讯云API调用配额使用情况

3. **报警设置**
   - 设置错误率阈值告警（如错误率超过5%）
   - 监控API响应时间，如超过阈值则告警
   - 配置腾讯云账户余额告警，避免因余额不足导致服务中断

## 日志管理

1. **结构化日志**
   - 使用结构化日志格式（JSON）便于解析和分析
   - 记录关键字段：请求ID、客户端IP、用户ID、请求参数（脱敏）、响应时间、错误类型

2. **日志分级**
   - INFO：正常请求记录
   - WARNING：性能降级、临时错误
   - ERROR：识别失败、API调用失败
   - CRITICAL：服务不可用、安全事件

3. **日志留存**
   - 生产环境保留至少30天的日志
   - 考虑将关键日志发送到中心化日志系统（如ELK Stack）

## 灾备策略

1. **故障转移**
   - 当主要区域不可用时，配置备用区域
   - 实现腾讯云API不可用时的优雅降级策略

2. **数据备份**
   - 定期备份关键配置和环境变量
   - 使用版本控制系统管理配置变更

3. **服务恢复**
   - 编写详细的故障恢复流程文档
   - 定期进行恢复演练，确保流程有效

## 成本优化

1. **API调用优化**
   - 在客户端进行初步的有效性验证，减少无效请求
   - 考虑对重复内容进行缓存（如果适用）

2. **资源监控**
   - 定期分析腾讯云计费账单，识别成本优化机会
   - 调整资源配置，避免过度配置导致成本浪费

3. **计费提醒**
   - 设置每日/每周API使用量报告
   - 配置成本超过预期时的告警机制
