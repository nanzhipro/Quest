# 语音识别服务安全备忘

## 密钥管理

1. **密钥保护**
   - 腾讯云API密钥（SecretId和SecretKey）必须妥善保管，不能硬编码到代码中
   - 使用环境变量或安全的密钥管理系统存储和获取密钥
   - 密钥应定期轮换（建议90天一次）

2. **最小权限原则**
   - 为语音识别服务创建单独的子账号/CAM用户
   - 仅分配必要的ASR服务相关权限，避免过度授权
   - 在腾讯云控制台开启操作保护和MFA验证

## API安全

1. **请求限制**
   - 客户端请求大小限制为3MB（已在控制器实现）
   - 建议配置API频率限制中间件，防止滥用（例如：每个用户每分钟10次请求）
   - 添加IP白名单或地域限制，减少恶意请求

2. **身份验证与授权**
   - 保持JWT令牌有效期较短（建议不超过24小时）
   - 实现令牌刷新机制，而不是颁发长期有效的令牌
   - 考虑在JWT令牌中添加用户权限声明，用于精细化控制

3. **数据保护**
   - 所有API调用必须通过HTTPS传输，确保数据加密
   - 服务器不应持久保存用户上传的语音数据
   - 语音识别结果应在必要时加密存储

## 漏洞防护

1. **输入验证**
   - 验证所有客户端输入，包括音频格式、大小和Base64编码的有效性
   - 实现请求超时机制，防止长时间阻塞

2. **错误处理**
   - 避免在错误响应中泄露敏感信息（如内部路径、详细堆栈跟踪等）
   - 错误日志记录应脱敏处理，不包含完整的用户数据
   - 使用通用错误消息，不暴露详细的技术信息

3. **依赖安全**
   - 定期更新所有依赖库，特别是有安全漏洞的库
   - 考虑使用依赖扫描工具监控潜在的安全漏洞

## 隐私合规

1. **数据处理**
   - 遵循数据隐私法规（如GDPR、CCPA等）的要求
   - 在隐私政策中明确说明语音数据的收集和处理方式
   - 允许用户撤回同意并删除其语音数据

2. **数据传输**
   - 确保跨境数据传输符合相关法规
   - 对于敏感语音数据，考虑使用就近区域的腾讯云服务
