我来帮您使用 Let's Encrypt 为 www.schedulesage.cn 申请免费的 TLS 证书。以下是具体步骤：

1. 首先，安装 certbot：

```bash
# Ubuntu/Debian
sudo apt update
sudo apt install certbot

# 或者使用 snap 安装（推荐）
sudo snap install --classic certbot
sudo ln -s /snap/bin/certbot /usr/bin/certbot
```

2. 申请证书：

```bash
# 使用 standalone 模式申请证书
# 注意：这需要暂时停止占用 80 端口的服务
sudo certbot certonly --standalone -d www.schedulesage.cn

# 或者使用 webroot 模式（如果已有 web 服务在运行）
sudo certbot certonly --webroot -w /var/www/html -d www.schedulesage.cn
```

3. 证书文件位置：
   成功后，证书文件会保存在：

- 证书：`/etc/letsencrypt/live/www.schedulesage.cn/fullchain.pem`
- 私钥：`/etc/letsencrypt/live/www.schedulesage.cn/privkey.pem`

4. 创建证书目录并复制证书：

```bash
# 创建证书目录
mkdir -p ./Docs/ssl

# 复制证书文件（需要 root 权限）
sudo cp /etc/letsencrypt/live/www.schedulesage.cn/fullchain.pem ./Docs/ssl/cert.pem
sudo cp /etc/letsencrypt/live/www.schedulesage.cn/privkey.pem ./Docs/ssl/key.pem

# 设置适当的权限
sudo chown -R $USER:$USER ./Docs/ssl
chmod 600 ./Docs/ssl/*.pem
```

5. 创建或修改 `.env` 文件，添加证书路径：

```bash
# .env
TLS_CERT_PATH=/app/certs/cert.pem
TLS_KEY_PATH=/app/certs/key.pem
SSL_CERT_DIR=./Docs/ssl
```

6. 设置证书自动续期：

```bash
# 测试自动续期
sudo certbot renew --dry-run

# 添加 cron 任务
sudo crontab -e

# 添加以下行（每天两次尝试续期）
0 0,12 * * * certbot renew --quiet --post-hook "docker compose restart app"
```

7. 验证配置：

```bash
# 启动服务
docker compose up -d

# 测试 HTTPS 连接
curl -v https://www.schedulesage.cn

# 检查证书信息
openssl s_client -connect www.schedulesage.cn:443 -servername www.schedulesage.cn
```

8. 证书续期后的自动部署脚本（创建 `renew-cert.sh`）：

```bash:renew-cert.sh
#!/bin/bash

# 复制新证书
sudo cp /etc/letsencrypt/live/www.schedulesage.cn/fullchain.pem ./Docs/ssl/cert.pem
sudo cp /etc/letsencrypt/live/www.schedulesage.cn/privkey.pem ./Docs/ssl/key.pem

# 设置权限
sudo chown -R $USER:$USER ./Docs/ssl
chmod 600 ./Docs/ssl/*.pem

# 重启 Vapor 应用
docker compose restart app
```

```bash
chmod +x renew-cert.sh
```

注意事项：

1. DNS 配置：

   - 确保 www.schedulesage.cn 的 DNS A 记录指向您的服务器 IP
   - 等待 DNS 记录生效（可能需要几分钟到几小时）

2. 防火墙配置：

   ```bash
   sudo ufw allow 80/tcp
   sudo ufw allow 443/tcp
   ```

3. 证书监控：

   - 设置证书过期提醒
   - 监控证书自动续期的日志
   - 建议设置至少 30 天前通知证书即将过期

4. 安全建议：
   - 定期备份证书和私钥
   - 限制证书文件的访问权限
   - 使用安全的密钥算法（Let's Encrypt 默认使用 RSA-2048）

这样配置后，您的 Vapor 应用就可以通过 https://www.schedulesage.cn 安全访问了，并且证书会自动续期。
