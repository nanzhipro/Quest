证书申请应该在 docker compose build 之前完成，因为容器需要挂载证书文件。让我为您详细列出操作步骤：

1. **准备工作**：

```bash
# 创建必要的目录
mkdir -p ./Docs/ssl
```

2. **申请证书**（在构建 Docker 镜像之前）：

```bash
# 停止可能占用 80 端口的服务
sudo docker compose down

# 安装 certbot
sudo snap install --classic certbot
sudo ln -s /snap/bin/certbot /usr/bin/certbot

# 申请证书
sudo certbot certonly --standalone -d www.schedulesage.cn

# 复制证书到项目目录
sudo cp /etc/letsencrypt/live/www.schedulesage.cn/fullchain.pem ./Docs/ssl/cert.pem
sudo cp /etc/letsencrypt/live/www.schedulesage.cn/privkey.pem ./Docs/ssl/key.pem

# 设置证书权限
sudo chown -R $USER:$USER ./Docs/ssl
chmod 600 ./Docs/ssl/*.pem
```

3. **创建/修改环境文件**：

```bash
# 创建 .env 文件
cat > .env << EOL
# TLS Configuration
TLS_CERT_PATH=/app/certs/cert.pem
TLS_KEY_PATH=/app/certs/key.pem
SSL_CERT_DIR=./Docs/ssl

# Database Configuration
POSTGRES_USER=vapor_username
POSTGRES_PASSWORD=vapor_password
POSTGRES_DB=vapor_database
VAPOR_DATABASE_NAME=vapor_database
VAPOR_DATABASE_USERNAME=vapor_username
VAPOR_DATABASE_PASSWORD=vapor_password

# Logging
LOG_LEVEL=info
EOL
```

4. **构建和启动服务**：

```bash
# 构建 Docker 镜像
docker compose build

# 启动服务
docker compose up -d

# 检查服务状态
docker compose ps
```

5. **验证 HTTPS 配置**：

```bash
# 测试 HTTPS 连接
curl -v https://www.schedulesage.cn/health

# 查看证书信息
openssl s_client -connect www.schedulesage.cn:443 -servername www.schedulesage.cn
```

6. **设置证书自动续期**：

```bash
# 设置续期脚本权限
chmod +x renew-cert.sh

# 测试证书续期
sudo certbot renew --dry-run

# 添加 cron 任务
sudo crontab -e
```

添加以下内容到 crontab：

```
# 每天凌晨 2:30 检查并续期证书
30 2 * * * certbot renew --quiet --post-hook "/path/to/your/project/renew-cert.sh"
```

7. **常用维护命令**：

```bash
# 查看容器日志
docker compose logs app

# 重启服务
docker compose restart app

# 停止所有服务
docker compose down

# 重新构建并启动（如代码更新后）
docker compose up -d --build
```

8. **故障排查**：

```bash
# 检查证书文件权限
ls -l ./Docs/ssl/

# 检查容器内证书挂载
docker compose exec app ls -l /app/certs/

# 查看详细日志
docker compose logs app --tail=100 -f

# 检查 TLS 配置
docker compose exec app cat /app/certs/cert.pem | openssl x509 -text -noout
```

注意事项：

1. **文件结构确认**：

```
your-project/
├── Docs/
│   └── ssl/
│       ├── cert.pem
│       └── key.pem
├── .env
├── docker-compose.yml
├── Dockerfile
└── renew-cert.sh
```

2. **权限检查清单**：

- 证书文件权限：600
- ssl 目录权限：700
- renew-cert.sh 权限：755

3. **安全建议**：

- 不要将证书文件提交到版本控制
- 在 .gitignore 中添加：

```
Docs/ssl/*.pem
.env
```

4. **备份建议**：

```bash
# 备份证书和配置
sudo tar czf ssl-backup-$(date +%Y%m%d).tar.gz \
    /etc/letsencrypt/live/www.schedulesage.cn/ \
    /etc/letsencrypt/archive/www.schedulesage.cn/ \
    /etc/letsencrypt/renewal/www.schedulesage.cn.conf
```

这样的操作流程确保了证书的正确申请、安装和自动续期，同时保证了 Docker 容器能够正确访问证书文件。
